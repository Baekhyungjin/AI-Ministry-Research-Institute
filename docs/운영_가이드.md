# 목회AI연구소 홈페이지 운영 가이드

## 폴더 구조

```text
목회AI연구소-홈페이지/
├─ public/
│  └─ images/
│     ├─ brand/      연구소 로고와 브랜드 이미지
│     ├─ about/      연구소 소개·프로필
│     ├─ schedule/   강의·세미나 사진
│     └─ archive/    8월·9월 매거진·출판·교육 자료
├─ src/
│  ├─ app/           실제 홈페이지 주소별 화면
│  ├─ components/    공통 화면과 관리자 기능
│  └─ lib/           데이터·Supabase 연결
├─ docs/              운영 및 이미지 문서
├─ supabase/          데이터베이스 마이그레이션
└─ .env.example       운영 환경값 견본
```

## 관리자에서 하는 일

1. `/login`에서 관리자 로그인
2. `/admin/applications`에서 문의와 강의 신청 확인
3. 접수 상태를 `새 접수 → 연락 완료 → 확정 → 종료` 순으로 변경
4. `/admin/content`에서 칼럼과 공지를 초안으로 작성하고 수정한 뒤 공개
5. `/admin/schedules`에서 강의 일정을 등록하거나 신청 마감

관리자에서 공개한 최신 공지와 신청 가능한 일정은 홈페이지의 `연구소 브리핑`과 상단 소식 영역에 자동으로 반영됩니다.

## 이미지 넣는 방법

이미지는 모두 `public/images` 아래 용도별 폴더에 넣습니다.

- 파일명에는 공백 대신 하이픈을 사용합니다.
- 한글 파일명도 가능하지만 영문 소문자를 권장합니다.
- 예: `hero/director-workshop-2026.webp`
- 예: `columns/ai-ministry-ethics-01.webp`
- 예: `schedule/gwangju-workshop-2026-09.webp`
- 홈페이지 코드에서는 `/images/hero/director-workshop-2026.webp`처럼 사용합니다.

## 실제 데이터 운영

운영 데이터는 Supabase에 저장되고 이미지는 `content-images` 버킷에 보관됩니다. 관리자 로그인에는 관리자 권한이 부여된 계정을 사용합니다. 개발 환경에서만 `로컬 예시 모드 열기` 버튼이 표시되며, Vercel 운영 환경에서는 관리자 인증 없이 콘텐츠를 수정할 수 없습니다.
