# 목회AI연구소 로고 사용 기준

## 기준 파일

- 홈페이지 심벌: `public/images/brand/ministry-ai-mark-transparent.png`
- 브라우저 아이콘: `src/app/icon.png`
- 보관용 원본: `public/images/brand/ministry-ai-logo-source.png`

웹 화면에는 투명 심벌만 사용합니다. 배경과 광원이 포함된 보관용 원본을 헤더, 푸터, 카드에 직접 넣지 않습니다.

## 표시 원칙

1. 로고 뒤에 흰색 사각형, 둥근 타일, 테두리 또는 그림자를 추가하지 않습니다.
2. `object-fit: contain`으로 전체 심벌을 표시하고 CSS 확대나 강제 크롭을 하지 않습니다.
3. 헤더와 푸터는 동일한 `BrandSymbol` 컴포넌트를 사용합니다.
4. 로고와 기관명 사이의 간격은 헤더 12px, 푸터 16px을 기준으로 합니다.
5. 밝은 배경과 어두운 배경 모두 같은 투명 PNG를 사용합니다.
6. 분홍·보라·파랑·청록 그라데이션은 강조 요소에만 사용하고 본문 가독성을 침해하지 않습니다.

## 교체 절차

새 로고가 제공되면 원본을 보관한 뒤 투명 PNG를 별도 생성하고, 밝은 배경과 어두운 배경에서 모두 검사합니다. 헤더와 푸터를 각각 따로 만든 이미지로 교체하지 않습니다.
