## 기획 근거 관리

디자인 사양서와 개인 사역 소개 원문은 공개 저장소에 포함하지 않고 연구소 내부 자료 폴더에서 관리합니다.

## 콘텐츠 분류에 반영한 연구소 사역

1. 지역교회 목회
2. AI 활용 연구
3. 목회자 교육
4. 교회용 도구 개발
5. 콘텐츠·출판
6. 선교·공공교육

원본의 AI 도구 문서 112개와 월별 결과물은 홈페이지에 직접 복제하지 않고, 향후 칼럼·자료실에 발행할 콘텐츠 원천으로 유지합니다. 이 방식이 중복 파일과 오래된 버전의 공개를 막습니다.
