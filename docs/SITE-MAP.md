# 목회AI연구소 홈페이지 사이트맵

## 공개 영역

- 홈 `/`
- 연구소
  - 연구소 소개 `/about`
  - 사역 프로젝트 `/projects`
  - 파트너 교회·개인 모집 `/partners`
  - 백형진 소장 디지털 명함 `/card`
- 연구·콘텐츠
  - 연구소 칼럼 `/columns`
  - 목회 인사이트 `/insights`
  - 프롬프트 자료 `/prompts`
  - 자료 아카이브 `/archive`
- 교육
  - 교육 일정 `/schedule`
  - 세미나 다시보기 `/replays`
  - 강의 요청 `/apply?type=lecture`
- GPT·앱
  - 무료·판매 GPT `/gpts`
  - 연구 결과 앱 `/apps`
- 소식·문의
  - 공지사항 `/notices`
  - 문의 및 강의 신청 `/apply`
- 전체 사이트맵 `/site-map`

## 운영자 영역

- 관리자 로그인 `/login`
- 운영 현황 `/admin`
- 문의·신청 관리 `/admin/applications`
- 칼럼·공지 관리 `/admin/content`
- 일정 관리 `/admin/schedules`
- GPT·앱·다시보기 관리 `/admin/resources`
- 파트너·시청 신청 관리 `/admin/leads`
- 인사이트 등록 `/admin/insights/new`
- 프롬프트 등록 `/admin/prompts/new`

## 핵심 데이터 흐름

1. 방문자가 칼럼·공지·프로젝트·교육 정보를 확인한다.
2. 일정, 강의, 일반 문의는 `/apply`에서 접수한다.
3. 파트너와 다시보기 신청은 각각의 공개 페이지에서 접수한다.
4. 접수 데이터는 관리자 화면에서 유형별로 확인하고 관리한다.
5. 칼럼·공지·일정·GPT·앱·다시보기는 관리자 화면에서 등록한다.

## 보류 영역

- `/membership`는 결제·권한·상품 정책이 확정되지 않은 임시 화면이므로 공개 메뉴와 검색엔진 사이트맵에서 제외한다.
