# 목회AI연구소 이미지 구성 제안

MiniMax 사양서의 핵심인 **넓은 흰 여백, 검정 CTA, 강한 컬러 카드**를 유지하면서 이미지는 장식이 아니라 연구소의 신뢰와 현장성을 증명하는 용도로 사용합니다.

현재 공식 로고, 백형진 소장 사진, 실제 세미나 포스터 3종을 원본 자료 폴더에서 선별해 홈페이지에 반영했습니다.

## 1. 메인 히어로 이미지

- 연구소장이 목회자들과 둥글게 앉아 노트북 화면을 보며 대화하는 실제 사진
- 인물의 시선이 화면 중앙의 제목을 향하도록 촬영
- 권장 비율: 원본 4:5, 데스크톱 크롭 5:6, 모바일 크롭 4:5
- 배경은 어두운 세미나실보다 밝고 정돈된 교육 공간이 적합
- 현재 구현된 추상 그래픽은 실제 사진이 준비될 때까지 사용할 수 있는 대체 비주얼

## 2. 네 개 서비스 카드의 그래픽

- 문의·신청(코랄): 서로 연결되는 두 개의 말풍선 또는 연결 노드
- 칼럼(마젠타): 문서 위에 겹쳐진 밑줄과 커서 형태
- 일정(블루): 날짜 블록과 이동 경로를 결합한 캘린더 그래픽
- 공지(퍼플): 중심에서 바깥으로 퍼지는 신호 파형
- 사람 사진을 네 장 반복하기보다 단색 선형 SVG 또는 반투명 3D 오브젝트로 통일

## 3. 강의·일정 이미지

- 실제 강의 현장 전경, 소그룹 실습, 화면을 함께 보는 손과 노트북의 디테일 사진
- 행사마다 사진이 없을 경우 날짜 숫자를 크게 쓴 컬러 포스터형 썸네일 사용
- 권장 비율: 16:9, 최소 1600×900px
- 참석자의 얼굴이 식별되는 사진은 게시 동의 여부 확인

## 4. 칼럼 대표 이미지

- 사진보다 제목 중심의 에디토리얼 OG 카드가 이 디자인에 잘 맞음
- 왼쪽 상단에 카테고리, 중앙에 2줄 제목, 하단에 연구소 로고 배치
- 카테고리별 색상: AI 목회=블루, 설교 연구=코랄, 콘텐츠=마젠타, 리더십=퍼플
- 권장 크기: 1200×630px. 블로그 목록용으로 16:9 안전 영역 확보

## 5. 연구소 소개 이미지

- 연구소장 정면 프로필 1장과 강의 현장 2장으로 충분
- 프로필은 검정 또는 흰 배경, 자연광, 과도한 AI 효과 없이 촬영
- 소개 페이지에서 인물 사진 옆에 비전 문장을 크게 배치

## 6. 신뢰를 만드는 보조 이미지

- 실제 교육 자료의 일부, 워크숍 노트, 강의 슬라이드, 참가자 결과물
- 협력 교회·기관 로고는 사용 허가를 받은 경우만 흑백으로 정렬
- 후기에는 가능하면 1:1 인물 사진을 사용하되, 동의가 없으면 교회명과 직분만 표기

## 피해야 할 이미지

- 로봇이 성경을 들고 있는 상투적인 생성 이미지
- 사람 손가락, 한글, 십자가 형태가 깨진 AI 이미지
- 컬러 카드 위에 또 강한 그라데이션이 들어간 복잡한 사진
- 출처와 사용 권한이 불분명한 교회·목회자 사진
